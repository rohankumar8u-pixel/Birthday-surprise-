# Betu's Birthday Surprise

A static website (HTML, CSS, JavaScript). No install or build step needed.

## Test on your computer
Open a terminal in this folder and run `python3 -m http.server 8000`, then visit http://localhost:8000
(Opening index.html by double-click also works in most browsers.)

## Get a link for WhatsApp (easiest: Netlify Drop, works from a phone or computer)
1. Go to https://app.netlify.com/drop and sign up or log in (free).
2. Drag this whole folder (the one containing index.html) onto the page. On a phone, upload the zip contents as a folder or use a computer.
3. Netlify gives you a public URL like https://something-random.netlify.app. Open it and test: tap the button and check music, photos and scrolling.
4. Optional: Site settings > Change site name for a nicer address.
5. Paste the link in WhatsApp.

## Alternative: Vercel
1. Create a free account at https://vercel.com and a GitHub repo with these files at the top level.
2. Add New > Project > import the repo > Framework Preset "Other" > Deploy.
3. Your link will be shown as https://your-project.vercel.app

## Swapping a photo or the song
Replace files in images/ (photo1-4.jpg) or music/birthday-song.mp3 keeping the same names.
The blurred backgrounds are images/bg1-4.jpg (small, blurred copies of the photos).
